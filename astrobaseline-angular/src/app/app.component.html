Methodology

For each astronaut we compute a personal baseline (median and robust sigma of the first N days using Median Absolute Deviation $\times 1.4826$). Status combines (1) demonstrative reference ranges and (2) deviation from the personal baseline ($z$-score), using the mean of the last 3 calendar days. Data quality = 60% coverage + 40% recency over 7 days.

Limitations & Ethics

Synthetic/demo data; demonstrative thresholds; no clinical validation; not a medical diagnosis device. Musculoskeletal evaluation (bone density loss) requires onboard imaging (DXA/ultrasound) and is not simulated here.
